# quiz (30–60 s, Short-first)
Beats: `reveal` the question (5) → `step` options A/B/C (6) → `countdown` 3 (3) → answer with `highlight` + `win` (4) → why: one `card` or `eq` (10) → CTA.
Long version = same beats; keep it under a minute. Every beat goes in the Short.
Mini example: see `examples/quiz-short.json`.
