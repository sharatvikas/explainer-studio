# timeline (2–5 min)
Beats: hook (the turning point) → `timeline` object in the stage, `step` one event per beat with narration → zoom (`camera`) on the key event → consequence `reveal` → recap.
Keep ≤ 7 events on one timeline; split eras into two timelines.
Mini example:
```json
{"id": "mughals", "type": "timeline", "zone": "stage", "events": [{"date": "1526", "text": "Panipat"}, {"date": "1556", "text": "Akbar"}, {"date": "1857", "text": "End"}]}
```
