# concept-explainer (2–5 min)
Beats: hook question (10) → intuition with a picture (30) → build up in 3–4 steps (`step` on a `flow`/`bullet_list`) (60) → the key formula/diagram (`eq` box) (20) → one worked example (40) → recap `reveal` (10).
Short cut: hook question → the key picture → the one-line answer.
Mini example: see `examples/photosynthesis-explainer.json`.
