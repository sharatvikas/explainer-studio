# worked-problem (3–6 min)
Beats (≈ seconds): hook race/paradox (20) → `title_card` (5) → setup with labels (30) → two tempting wrong answers (25) → show the answer visually: sweep/trace/race (25) → derivation, 3–5 `eq` (60) → twist/insight (20) → numbers + rematch (30) → challenge question (10).
Short cut: hook + the visual answer + boxed result + twist (4–6 beats).
Use: `params` + `tween` for anything that varies; `graph` with `trace`; `eq` with `box` on the result; `reveal` for the named principle.
Mini example: see `examples/irodov-1-17.json`.
